# The Executive Framework

Working with threads is complex and error prone.&#x20;

So, Java 5 introduced higher level abstractions that simplify building concurrent applications.&#x20;

With these abstractions, we don't need to explicitly work with threads.&#x20;

Instead, we can focus on our tasks and **let Java take care of thread manipulation**.
