# Primitive Type Streams

## Primitive Type Streams

> **java.util.stream.IntStream** interface
>
> * `.of(n)`: returns a sequential IntStream containing a single element
> * `.of(int...)`: returns a sequential ordered stream whose elements are the specified values
> * `.generate(IntSupplier)`: returns an infinite sequential unordered stream where each element is generated by the provided IntSupplier
> * `.range(startInclusive, endExclusive)`: returns a sequential ordered IntStream from startInclusive (inclusive) to endExclusive (exclusive) by an incremental step of 1
> * `.range(startInclusive, endInclusive)`: returns a sequential ordered IntStream from startInclusive (inclusive) to endInclusive (inclusive) by an incremental step of 1
>
> **java.util.stream.LongStream** interface
>
> **java.util.stream.DoubleStream** interface



***

```java
import java.util.stream.IntStream;

public class StreamsDemo {

    public static void main(String[] args) {
        // IntStream: of()
        IntStream.of(1,2,3)
                        .forEach(m -> System.out.print(m + " ")); // Output: 1 2 3

        // IntStream: rangeClosed()
        IntStream.rangeClosed(1, 5)
                .forEach(m -> System.out.print(m + " ")); // Output: 1 2 3 4 5

        // IntStream: range()
        IntStream.range(1, 5)
                .forEach(m -> System.out.print(m + " ")); // Output: 1 2 3 4
    }

}
```
