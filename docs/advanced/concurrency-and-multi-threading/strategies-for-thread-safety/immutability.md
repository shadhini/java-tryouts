# Immutability

## Immutability

> **— using immutable or unchangeable objects —**&#x20;
>
> **Sharing immutable objects between threads is totally fine**, as threads can only read immutable objects. They cannot modify them.

#### Immutable Object

* An object is immutable, if it's data cannot be changed after it's created
  * e.g: String class in Java: if we convert a string to uppercase, we get a new String object; The original string object is unchanged,&#x20;
