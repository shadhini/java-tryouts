# Partitioning

## **Partitioning**

> **— Partitioning data into segments that can be accessed concurrently —**&#x20;



* <kbd>Java provides a number of</kbd> <kbd></kbd><kbd>**collection classes**</kbd> <kbd></kbd><kbd>that support concurrency using partitioning.</kbd>
  * So, **multiple threads can access** a collection object, **but only one thread at a time can access a segment in that collection**.
